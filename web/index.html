    DeepSeek API Key（仅保存本地）

    用于「AI 增强周报」「模板 AI 解析」与「Word/PDF 文本提炼」。Key 只会写入本机的 config/keys.json （已被 .gitignore 排除，不会进入 git），接口只返回脱敏信息，不会泄漏到任何服务器。

    说明

    • 环境变量 DEEPSEEK_API_KEY 优先于本地文件；两者都没配置时，AI 功能自动回退为规则引擎文案。
    • 「测试连接」会发送一条最小请求到 DeepSeek 官方接口验证 Key 是否可用（未保存的输入不会被写入磁盘）。
    • 清除操作只删除本地文件中的 Key，不影响系统环境变量。

    AI 模型与接口（仅保存本地）

    选择生成周报/提炼文本使用的模型与 API 地址。配置只写入本机 config/keys.json，不会上传。

    deepseek-chat 通用性价比高；deepseek-reasoner 推理增强、更贵更慢、综述更深刻

    AI 提示词（可编辑调试）

    修改保存后，生成/提炼/模板解析立即生效（仅本地 config/prompts.json）。 User 模板里的 {stats_json} 等占位符由系统填充；「示例」区可贴您期望的输出样稿（多个用 --- 分隔），AI 会模仿其风格——比如您想让综述写成"本周完成 X 项，待完成 Y 项，卡点在于…"，把样稿贴进综述的示例即可。
